# XiangShan reproducers

Standalone reproducers for issues filed against [OpenXiangShan/XiangShan](https://github.com/OpenXiangShan/XiangShan). Each directory has a README.md, the source, a prebuilt ELF, a run.sh, and the observed and expected output. Each `<directory>.tar.gz` at the top level holds the same files.

| Issue | Directory | Tarball |
|---|---|---|
| [XiangShan#ISSUE](https://github.com/OpenXiangShan/XiangShan/issues/ISSUE) | [xiangshan-vector-trigger-tval](xiangshan-vector-trigger-tval/) | [xiangshan-vector-trigger-tval.tar.gz](xiangshan-vector-trigger-tval.tar.gz) |
